# UX Profile

Written from the founders' decisions for the M2P Nexus marketing site (VectorLab `product-profile` template).
All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Custom: Stripe-level restraint with Madurai warmth
- **Notes:**
  - This is a **marketing site**, not a product app. Pages are marketing route types (VectorLab
    `page-patterns/reference/marketing.md`); the booking page is **Pattern 3 — Form**.
  - Palette (tokens in `src/index.css`): ink `#172554` (60% canvas partner on dark bands), white / paper
    `#F4F6FA` canvases, rule `#D6E0F0` hairlines, leaf `#1F6B3A` (WhatsApp and positive states), one accent:
    marigold `#F2A900`. Marigold is the only accent hue for emphasis; green is reserved for WhatsApp/success.
  - Brand motifs: handwritten Tamil paper (Kavivanar), the roots-to-network line, the gold seal. Each signature
    visual lives on **one page only** (no repeated hero images or videos across pages).
  - Elevation: 1px hairline (`ring-rule`) first, then `shadow-soft` / `shadow-lift` (light-mode alpha < 0.08).
    Dark ink bands may use a gold glow on illustrations only.

## Banned anti-aesthetics

- Rainbow or multi-hue gradients on CTAs (the conic "orb" is a decorative mark, never a button fill)
- Glassmorphism / `backdrop-filter` panels
- Cartoon people, stock photos of handshakes, emoji as UI icons
- Decorative pills around static facts (timings, metadata); pills only for interactive filters or
  status inside illustrations
- Invented metrics, client quotes, ratings or prices (brand guide: only founder-confirmed facts)
- Printed phone numbers (calls and WhatsApp are icon buttons; numbers live only in `tel:` / `wa.me` links)
- Infinite decorative loops on chrome (header, footer, floating buttons, dialogs)

## Accessibility target

- **Level:** WCAG 2.1 AA (plus 2.5.8 target size)
- **Contrast:** 4.5:1 body text, 3:1 large text and UI parts; gold text only on ink, never on white
- **Touch / focus:** 44×44px hit targets for every control; visible `:focus-visible` ring (3px) on every
  interactive element, including hidden range inputs (ring shown on the visible handle)

## Typography

- Body Hind Madurai 400; UI emphasis 600; headlines Archivo / Archivo Expanded **700**.
- **Deliberate exception:** display headlines use weight 700 (VectorLab default caps at 600). Never 800+.
- Sizes: body 16px, secondary 14px, meta 12px; nothing below 12px. Tamil text uses Hind Madurai (no
  Archivo Expanded for Tamil glyphs).

## Motion

- Chrome (header, menus, buttons, tooltips): 100 / 150 / 200 / 300ms, ease-out in, ease-in out,
  transform/opacity only, no loops.
- **Deliberate exception:** illustration choreography (scenes, the scroll story, the film, blueprints,
  the digitise hint sweep) may run longer, but plays once, uses transforms, and stops for
  `prefers-reduced-motion: reduce`. Meaning is always also in text.

## Brand tone and microcopy voice

- **Voice:** Warm & Humancentric (M2P Nexus brand guide: business-outcome first, partner not vendor,
  grounded, MSME-empathetic)
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** Verb-first buttons ("Book my consultation", "Ask this on WhatsApp"). Lead with the customer's
  problem. English and Tamil (`/ta/`) are both first-class; Tamil copy should be reviewed by a native speaker.

## Icon library

- **Library:** Lucide
- **Package / path:** `lucide-react`; brand marks (WhatsApp, LinkedIn) in `src/components/icons.jsx`
- **Notes:** Icon-only controls use `src/components/Tooltip.jsx` (hover + focus) and a matching
  verb-first `aria-label`.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome →
   `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`;
   motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
6. Tasks over ~10 seconds get their own page (e.g. `/book/`), never a modal.
